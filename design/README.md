# Дизайн LumenBook

Кликабельные макеты сервиса бронирования залов по техническому заданию.

| Файл | Что внутри |
|---|---|
| [LumenBook.figcraft](LumenBook.figcraft) | Макет и кликабельный прототип для FigCraft |
| [LumenBook-screens.pdf](LumenBook-screens.pdf) | Все 65 экранов в PDF, открываются без FigCraft |

## Как открыть

1. Установите бесплатный [FigCraft](https://getartcraft.com/apps/figcraft), регистрация не нужна.
2. Откройте `LumenBook.figcraft`.
3. Прототип: кнопка ▶ вверху справа → «Презентация». На стартовом экране можно выбрать роль или один из 6 сценариев из ТЗ.
4. Размеры, цвета, отступы и CSS: режим Dev Mode.

## Страницы файла

- **Общие элементы** — цвета, шрифты, иконки, кнопки в 4 состояниях, поля, статусы брони, состояния часового слота.
- **Прототип** — стартовый экран и экраны администратора, 1366×768.
- **Прототип · клиент (телефон)** — экраны клиента, 375 px.

Экраны названы по ТЗ: К1–К9 — клиент, А1–А6 — администратор. В демо «сейчас» — пт, 13 ноября 2026, 14:40. Все данные вымышленные.
