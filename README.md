# Сервис онлайн-бронирования залов фотостудии «Lumen Studio» (LumenBook)

Веб-сервис для автоматизации бронирования 4 съёмочных залов студии («Циклорама», «Лофт», «Неон», «Сканди»), устранения проблемы двойных броней (овербукинга) и централизованного ведения расписания администратором.

## 📂 Проектная документация (Артефакты Фаз 1–4)

Все материалы систематизированы и доступны в каталоге `docs/`:

1. **Концепция и требования (Фаза 1):**
   * `docs/Концепт-документ.docx` — описание предметной области, 16 ответов заказчика, границы решения.
2. **Базовые документы (Фаза 2):**
   * `docs/Устав_проекта.docx` — цели SMART, полномочия PM, границы (Out-of-Scope), чек-лист приёмки.
   * `docs/Реестр_заинтересованных_сторон.xlsx` — 9 внешних стейкхолдеров, матрица «влияние-интерес», план коммуникаций.
   * `docs/ИСР_LumenBook.pdf` — иерархическая структура работ на 25 пакетов и словарь ИСР.
   * `docs/Анализ_методологий_и_ЖЦ.pdf` — модели Киневин, Agile Suitability Model и обоснование гибридного подхода.
3. **План по срокам и рискам (Фаза 3):**
   * `docs/Сводная_таблица_оценок_и_PERT.xlsx` — 3-точечные оценки трудоёмкости (387 ч), бюджет (209 850 ₽), критический путь (197 ч), Z-расчёт вероятности сдачи (98,3%) и таблица резервов (TF, FF).
   * `docs/Реестр_рисков.xlsx` — 12 рисков с качественной оценкой, планами реагирования (План А) и «Планами Б».
   * `docs/Расписание_LumenBook_Гант.png` — календарный план проекта с 17.09 по 24.12 с контрольными вехами.
4. **Подготовка к разработке (Фаза 4):**
   * `docs/User_Story_Map_и_Бэклог.md` — карта пользовательских историй по ролям Клиента и Администратора с кодами ИСР, приоритизация по MoSCoW, нарезка на 4 спринта.
   * `docs/Журнал_изменений.xlsx` — журнал фиксации запросов на изменения от заказчика на демонстрациях.

## ⚙️ Планируемый стек технологий (Спринты 1–4)

* **Backend:** Python 3.11, FastAPI, SQLAlchemy, Alembic (миграции БД).
* **Database:** PostgreSQL 15.
* **DevOps:** Docker, Docker Compose.
* **Frontend:** Адаптивный веб-интерфейс (HTML5, CSS3, JavaScript) под мобильные экраны (375 px) и десктоп администратора.

## 🚀 Инструкция по развёртыванию

*Раздел наполняется разработчиком по мере сдачи пакета ИСР 3.1.1 (Спринт 1).*

После публикации образов запуск прототипа будет осуществляться командой:

    docker compose up --build

* **Клиентская витрина:** http://localhost:8000
* **Кабинет администратора:** http://localhost:8000/admin
* **Интерактивная документация API (Swagger):** http://localhost:8000/docs
