# Сервис онлайн-бронирования залов фотостудии «Lumen Studio» (LumenBook)

Веб-сервис для автоматизации бронирования 4 съёмочных залов студии («Циклорама», «Лофт», «Неон», «Сканди»), устранения проблемы двойных броней (овербукинга) и централизованного ведения расписания администратором.

## 🚀 Инструкция по развёртыванию

Требования: Docker Desktop с Linux-контейнерами и Docker Compose v2. Локальная установка Python и PostgreSQL для запуска через Docker не нужна.

Из корня репозитория в PowerShell:

```powershell
Copy-Item .env.example .env
docker compose up --build --detach --wait
docker compose exec app python -m scripts.seed_rooms
```

Если `.env` уже существует, используй его без повторного копирования. Образ приложения собирается локально из Dockerfile. PostgreSQL должен пройти проверку готовности, затем приложение автоматически применяет миграции Alembic и запускает сервер.

Доступные адреса:

* **Стартовая страница и список залов:** http://localhost:8000
* **Вход:** http://localhost:8000/login
* **Регистрация:** http://localhost:8000/register
* **Раздел администратора:** http://localhost:8000/admin
* **Проверка приложения и БД:** http://localhost:8000/health
* **Swagger:** http://localhost:8000/docs
* **Схема OpenAPI:** http://localhost:8000/openapi.json

При доступной БД `/health` возвращает `200` и `{"status":"ok","database":"ok"}`, при ошибке подключения — `503`. После регистрации клиент сразу входит в аккаунт. На главной отображается каталог; информация аккаунта открывается по аватару в шапке. Расписание и бронирование добавляются на следующих этапах.

### Настройки

| Переменная | Значение в примере | Назначение |
| --- | --- | --- |
| `APP_PORT` | `8000` | Порт приложения на localhost |
| `POSTGRES_DB` | `lumenbook` | Имя базы данных |
| `POSTGRES_USER` | `lumenbook` | Пользователь PostgreSQL |
| `POSTGRES_PASSWORD` | `lumenbook_local` | Пароль локальной БД |
| `POSTGRES_HOST` | `db` | Адрес БД для Python-команд вне Compose |
| `POSTGRES_PORT` | `5432` | Порт БД для Python-команд вне Compose |

Compose подключает приложение к `db:5432` во внутренней сети. Порт PostgreSQL на хост не публикуется. `.env` исключён из Git и контекста сборки. Изменение пользователя, пароля или имени БД в `.env` не перенастраивает уже инициализированный volume PostgreSQL.

### Авторизация

Регистрация доступна по имени, телефону или email и паролю 8–128 символов. Требуется согласие на обработку данных; время согласия сохраняется в БД. Публичная регистрация создаёт только клиента. Используй вымышленные контакты.

Создание администратора с интерактивным вводом пароля:

```powershell
docker compose exec app python -m scripts.create_admin --name "Администратор" --identifier admin@lumenbook.ru
```

Повторный запуск не меняет существующий пароль. Пароли хешируются Argon2id, токены сессий хранятся в БД только в виде хеша. Сессия действует 12 часов; выход завершает текущую сессию. `SESSION_TTL_HOURS` задаёт срок, `SESSION_COOKIE_SECURE=true` включает Secure для HTTPS. При локальном HTTP оставь `false`. Обе настройки передаются приложению из `.env`.

Формы повторяют макеты Figcraft: Inter, одно поле телефона/email, показ пароля, ошибки под полями. Демо-переключатель ролей отсутствует. `/admin` требует роль администратора и пока показывает залы, без расписания.

### Каталог залов

Каталог `/` и карточки `/rooms/{room_id}` доступны без входа. API: `GET /api/v1/rooms` возвращает `items`, `GET /api/v1/rooms/{room_id}` — один зал. Цена, описание и часы работы читаются из PostgreSQL. Для отсутствующего зала API возвращает `404 ROOM_NOT_FOUND`, HTML-страница — экран с возвратом в каталог.

Мобильная вёрстка повторяет экраны K2.1 и верхнюю часть K3 из Figcraft; на широком экране каталог занимает две колонки. Иллюстрации экспортированы из макета в локальные SVG. При отсутствии изображения показывается текстовое состояние. Доступность, выбор даты и времени, бронирование подключаются отдельным этапом.

### Миграции и данные

```powershell
docker compose exec app alembic current
docker compose exec app alembic check
docker compose exec app python -m scripts.seed_rooms
docker compose exec db psql -U lumenbook -d lumenbook -c "SELECT name, hourly_price_minor, opens_at, closes_at FROM rooms ORDER BY name;"
```

Команда `psql` приведена для значений `.env.example`; при изменении настроек замени пользователя и имя БД. Скрипт создаёт четыре зала со ставками из концепт-документа и часами работы 09:00–23:00. Описания и иллюстрации взяты из макетов Figcraft. Повторный запуск не создаёт дубликаты, сохраняет цены, часы работы и заполненный контент; у старых записей дополняются только пустое описание и отсутствующее изображение. Цены хранятся в копейках.

Остановка с сохранением данных:

```powershell
docker compose down
docker compose up --detach --wait
```

Данные сохраняются в volume `lumenbook_postgres_data`. Команда `docker compose down --volumes` удаляет этот volume вместе со всеми данными проекта.

Логи приложения и PostgreSQL:

```powershell
docker compose logs --tail 100 app db
```

### Проверки

Интеграционные проверки используют отдельную БД `lumenbook_test`. Они проверяют миграции, ограничения таблицы, повторное заполнение с сохранением изменённых данных, шаблоны, статику и ответы `/health` при доступной и недоступной БД. Проверки авторизации охватывают регистрацию, дубликаты и гонки, хеширование, согласие, сессии, CSRF и роли. Для каталога проверяются API, актуальность цены и часов работы, отсутствие зала и изображения, пустой список и экранирование HTML.

Для настроек из `.env.example`:

```powershell
docker compose exec db createdb -U lumenbook lumenbook_test
docker build --target test -t lumenbook-tests .
docker run --rm --network lumenbook_default --env-file .env -e POSTGRES_HOST=db -e TEST_DATABASE_URL=postgresql+psycopg://lumenbook:lumenbook_local@db:5432/lumenbook_test lumenbook-tests
docker run --rm --env-file .env lumenbook-tests ruff check --no-cache .
```

Тестовую БД нужно создать один раз. При изменении настроек замени пользователя и строку подключения в командах. Проверки изменяют только БД с точным именем `lumenbook_test`; указывать рабочую базу нельзя.
