# Сервис онлайн-бронирования залов фотостудии «Lumen Studio» (LumenBook)

Веб-сервис для автоматизации бронирования 4 съёмочных залов студии («Циклорама», «Лофт», «Неон», «Сканди»), устранения проблемы двойных броней (овербукинга) и централизованного ведения расписания администратором.

## 🚀 Инструкция по развёртыванию

Требования: Docker Desktop с Linux-контейнерами и Docker Compose v2. Локальная установка Python и PostgreSQL для запуска через Docker не нужна.

Из корня репозитория в PowerShell:

```powershell
Copy-Item .env.example .env
docker compose up --build --detach --wait
```

Если `.env` уже существует, используй его без повторного копирования. Образ приложения собирается локально из Dockerfile. Compose ожидает готовности PostgreSQL и запускает приложение.

Доступные адреса:

* **Стартовая страница:** http://localhost:8000
* **Проверка приложения:** http://localhost:8000/health
* **Swagger:** http://localhost:8000/docs
* **Схема OpenAPI:** http://localhost:8000/openapi.json

`/health` возвращает `200` и `{"status":"ok"}`. Каталог, авторизация и кабинет администратора появятся на следующих этапах.

### Настройки

| Переменная | Значение в примере | Назначение |
| --- | --- | --- |
| `APP_PORT` | `8000` | Порт приложения на localhost |
| `POSTGRES_DB` | `lumenbook` | Имя базы данных |
| `POSTGRES_USER` | `lumenbook` | Пользователь PostgreSQL |
| `POSTGRES_PASSWORD` | `lumenbook_local` | Пароль локальной БД |
| `POSTGRES_HOST` | `db` | Адрес БД для Python-команд вне Compose |
| `POSTGRES_PORT` | `5432` | Порт БД для Python-команд вне Compose |

Compose подключает приложение к `db:5432` во внутренней сети. Порт PostgreSQL на хост не публикуется. `.env` исключён из Git и контекста сборки. Изменение пользователя, пароля или имени БД в `.env` не перенастраивает уже инициализированный volume PostgreSQL.

Остановка с сохранением данных:

```powershell
docker compose down
docker compose up --detach --wait
```

Данные сохраняются в volume `lumenbook_postgres_data`. Команда `docker compose down --volumes` удаляет этот volume вместе со всеми данными проекта.

Логи приложения и PostgreSQL:

```powershell
docker compose logs --tail 100 app db
```
